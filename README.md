# Pornhub Viewer для Lampa

Клиентский плагин для Lampa, который добавляет в главное меню пункт `Pornhub 18+`.

Возможности:

- поиск по официальному сайту Pornhub;
- открытие ролика по ссылке `viewkey` или `/embed/…`;
- открытие главной страницы сайта;
- локальное подтверждение возраста 18+ с возможностью сброса.

## Установка

1. Разместите `pornhub-viewer.js` на HTTPS-хостинге.
2. В Lampa откройте `Настройки → Расширения → Добавить плагин`.
3. Вставьте URL файла и перезапустите Lampa.

Для локальной проверки файл можно подключить с любого доступного в вашей сети HTTPS-сервера.

## Важно

Плагин открывает официальный сайт через браузер устройства или нативный мост Android. Он не скачивает видео, не извлекает временные MP4/HLS-ссылки и не обходит географические, возрастные или антибот-ограничения Pornhub.

Причина: публичный клиентский API Pornhub для каталога и потоков не заявлен, а браузерный плагин Lampa не может надёжно получить поток с другого домена из-за CORS и ограничений WebView. Для полностью встроенного просмотра нужен отдельный серверный провайдер с разрешённым API и собственной политикой доступа.
